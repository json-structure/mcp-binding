## Why JSON Structure for MCP?

[`why-json-structure-for-mcp.md`](why-json-structure-for-mcp.md) is a companion
to the specification. The draft defines the mechanics of the binding; the
companion makes the case for it, and concentrates on what JSON Structure's
annotation model gives a language model that a bare JSON Schema cannot:
alternate and localized names, units and currencies, semantic annotations, and
relations between the values one tool returns and the arguments another tool
accepts.
